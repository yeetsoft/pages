## What this repo is

Public static hosting for selected YeetSoft projects, published via GitHub Pages at https://yeetsoft.github.io/pages/.

**This repo is a deploy target, not a place for manual edits.** Content under project subdirectories (`binary-clock/`, `imprint/`) is pushed here automatically by a workflow in the private `pyc` repo whenever those projects change on `main`. The root `index.html` is also regenerated by that workflow. Manual changes to those subdirectories or the root `index.html` will likely be overwritten by the next automated push — treat edits there as temporary/exploratory unless the user explicitly wants to override the generated content.

`homepage/` is the exception: it is the YeetSoft landing page and is maintained directly in this repo.

## Architecture

Each top-level directory is an independent, static, dependency-free web app — no build step, no bundler, no package manager, no shared code between them:

- `binary-clock/` — binary clock display. Open `index.html` directly.
- `imprint/` — book cover designer with PDF export. Open `imprint.html` directly.
- `homepage/` — the YeetSoft marketing/landing page (`index.html`), linking out to the other project subdirectories.
- `index.html` (root) — auto-generated directory listing linking to each subdirectory.

There is no build, lint, or test tooling in this repo. To work on any app, open its HTML file directly in a browser.

## Deployment

GitHub Actions workflow at `.github/workflows/pages.yml` deploys the entire repo root as-is to GitHub Pages on every push to `main` (or manual dispatch). There is no build step in CI — files are uploaded and served verbatim.
